# MiniRec — Win11 极简原生隐身录屏 & 微信式截图工具

纯原生、零外部依赖（无需 FFmpeg / OCR 语言包模型）、单文件绿色版（**< 0.5 MB**）Windows 11 桌面截图与隐身录屏一体化工具。

## 核心特性

1. **录屏自动隐身（兼容远程桌面）**
   - 仅在录屏期间对悬浮控制条与选区边界红框调用 Win32 `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`：录出的 MP4 中**绝不会出现软件自身**，平时则保持可见，兼容 UU 远程 / ToDesk 等远程桌面操控。
   - 所有提示均在悬浮条内联显示，不弹系统 `MessageBox`。
2. **微信式冻结截图 & 放大镜取色**
   - 按 `F1`（或点击悬浮条 `✂` / 托盘「屏幕截图」）瞬间冻结全虚拟桌面，连右键菜单与悬浮层均可定格。
   - 支持 **UI Automation 子控件级自动吸附**（滚轮可在子控件 ↔ 父容器 ↔ 顶层窗口间切换层级）。
   - 实时 **9x 放大镜 + 十字准星取色**（`Shift` 切换 HEX / RGB，`C` 复制当前像素色值）。
3. **全套矢量标注工作台 + 双模式马赛克**
   - 支持矩形（`Shift` 正方形）、椭圆（`Shift` 正圆）、流线实心箭头、画笔、半透明荧光笔、自动序号圆标（①②③）、马赛克（像素块 / 高斯模糊双模式）与原位透明文字标注。
   - 支持二级粗细/色板浮条、`Ctrl+Z` / `Ctrl+Y` 撤销重做、点击已有标注拖动微调或 `Delete` 删除，1:1 物理像素无损合成导出（`Enter`/双击复制剪贴板、`Ctrl+S` 存 PNG、`●` 一键转为该区域隐身录屏）。
4. **桌面置顶贴图（Pin）**
   - 支持多张图片原地钉在桌面置顶显示，左键拖动、滚轮无级缩放（15%–400%）、`Ctrl+滚轮` 调透明度、双击/`Esc` 关闭；右键支持复制、保存 PNG、提取文字 OCR 与切换「录屏时隐身」。
5. **纯手工 WinRT COM 离线 OCR（原图自由划词）**
   - 无需任何第三方模型包，直接调用 Win11 原生离线 `OcrEngine` 毫秒级识别中英文。
   - 截图后按 `O` 或点「文」直接在原图实现微信式**逐字/跨行自由拖选高亮**、双击选整行、`Ctrl+A` 全选，松手即现「复制 / 去换行复制」气泡，并支持弹出可自由缩放的独立文本编辑大窗。
6. **Win11 原生 Media Foundation 编码 & WASAPI 混音**
   - 无需打包 FFmpeg，直接调用系统原生 `IMFSinkWriter`（自动优先核显/独显硬编，失败回退软编）写入 `H.264 + AAC 192kbps` 标准 MP4。
   - 默认 **`60 FPS`** + **`🎧 系统声音 + 麦克风混音`**（支持四档切换与帧率切换）。
7. **零冲突黄金全局快捷键 & 托盘增强**
   - `F1`：微信式屏幕截图（参考 Snipaste / PixPin 零冲突单键）
   - `Shift + F1`：开始 / 停止录屏（避开浏览器强刷与显卡热键）
   - `Ctrl + Alt + H`：显示 / 隐藏悬浮控制条
   - 右键系统托盘支持：**开机自启动（`--minimized` 静默驻留）**、**自定义快捷键**、**关闭按钮行为设置**（首次询问并可记住「最小化到托盘 / 彻底退出」）、**关于 MiniRec**。

## 运行与发布

- **直接运行单文件绿色版**（仅此 1 个 `.exe` 即可拷贝到任意位置运行）：
  ```text
  D:\myscript\mini-screen-recorder\dist\MiniRec.exe
  ```
- **一键打包发布单文件**：
  ```powershell
  .\publish.ps1
  ```
- **运行无界面内置自检**：
  ```powershell
  .\dist\MiniRec.exe --self-test
  ```
- 默认保存目录：录屏 `视频\MiniRec\`（`Rec_yyyyMMdd_HHmmss.mp4`），截图 `图片\MiniRec\`（`Shot_yyyyMMdd_HHmmss.png`），配置保存在 `%LocalAppData%\MiniRec\config.json`。
