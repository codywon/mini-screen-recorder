# MiniRec — Win11 极简原生隐身录屏工具

纯原生、零外部依赖（无需 FFmpeg）、单文件绿色版（**< 1 MB**）Windows 11 桌面录屏工具。

## 核心特性

1. **录屏完全隐身**
   - 对悬浮控制条与选区边界红框调用 Win32 `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`，你在屏幕上正常看到，但录出来的 MP4 中**绝不会出现软件自身**。
   - 所有提示均在悬浮条内联显示，不弹系统 `MessageBox`。
2. **Win11 原生 Media Foundation 编码**
   - 无需打包 FFmpeg，直接调用系统原生 `IMFSinkWriter`（自动优先核显/独显硬编，失败自动回退系统软编），写入 `H.264 + AAC 192kbps` 标准 MP4。
3. **WASAPI 原生录音 & 实时混音**
   - 默认开启 **`🎧 全部`（系统声音 + 麦克风混音）**，可在悬浮条或托盘 `录音` 菜单中一键切换四档：
     - `🎧`：系统声音 + 麦克风实时混音（默认，带防爆音软限幅）
     - `🔊`：仅录系统/电脑播放声音（WASAPI Loopback）
     - `🎤`：仅录麦克风
     - `🔇`：静音（不录声音）
4. **帧率调节**
   - 默认 **`60 FPS`**，点击悬浮条帧率按钮或托盘 `帧率` 菜单，可在 `15 / 24 / 30 / 60 FPS` 间切换并自动保存配置。
5. **微信截图式区域框选**
   - 点击 `⛶`（或托盘 `框选区域...`）进入透明遮罩，自动吸附高亮前端窗口；单击锁定或按住拖动自由拉框。
   - 锁定/松手后选框**停留在屏幕上**，支持拖动 **8 个绿色手柄/四边**缩放、拖动**内部**平移、方向键微调（`Shift` 10px）。
   - 工具条支持 `● 录制`（确认并立刻开录）、`↺`（重选）、`✕`（取消/`Esc`）、`✓`（确认/`Enter`/双击）。右键恢复全屏。
   - 选区录制时外沿 2px 显示**隐身穿透红框**提示边界。
6. **全局快捷键 & 极简悬浮条拖动**
   - `Ctrl + Alt + R`：开始 / 停止录制
   - `Ctrl + Alt + H`：显示 / 隐藏悬浮控制条
   - 右键系统托盘图标 → **`设置快捷键...`** 可在隐身弹窗中修改以上两个快捷键（或恢复默认）。
   - 按住悬浮条左侧 `⋮⋮` 拖动抓手、计时区或空白处即可任意拖动位置。

## 运行与发布

- **直接运行单文件绿色版**（仅此 1 个 `.exe` 即可拷贝到任意位置运行，区别于开发编译目录 `bin\Release\`）：
  ```text
  D:\myscript\mini-screen-recorder\dist\MiniRec.exe
  ```
- **一键打包发布单文件**：
  ```powershell
  .\publish.ps1
  ```
- **运行无界面内置自检**：
  ```powershell
  .\dist\MiniRec.exe --self-test
  ```
- 默认保存目录：`视频\MiniRec\`（`Rec_yyyyMMdd_HHmmss.mp4`），配置保存在 `%LocalAppData%\MiniRec\config.json`。
